UX/UI Frictions

1. As a low-tech, price-checking evaluator, I wanted to verify cost before giving any personal information.
Add a clearly labeled Pricing link to the top navigation on the homepage and About page so first-time visitors can check cost before clicking Start Learning.
2. It took way too many clicks to find a Pricing link - it's buried in the footer instead of the main nav, which feels…
The persona's own words at that moment: “There's a Pricing link right there in the footer. Let me finally click that and see the actual cost.”
3. The homepage made me question whether this was really a spoken-English tutor or a generic AI tools directory.
On the homepage, remove or visually separate unrelated AI tool cards from the TalkBerry tutor experience, and place spoken-English practice content and examples above them.
4. I expected to preview how practice works before being asked to create an account.
Before the signup form, add a visible lesson preview or interactive demo on the homepage and Start Learning entry point, with a short explanation of what practice looks like.
