Why this costs trust
An opaque failure on the headline feature, on the first URL an evaluator brings, poisons everything downstream: every later feature is judged by a buyer who has already seen the core one fail silently.

Return the actual reason (blocked by robots, fetch timeout, TLS, non-HTML), retry with backoff automatically, and show per-page progress so a partial crawl is not reported as a dead one.
