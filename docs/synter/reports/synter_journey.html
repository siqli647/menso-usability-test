Where Synter lost Declan

MAJORSteps 10–12
1. Seeing real campaign data requires a live ad account — there is no sample path on the evaluation trail.
“OAuth popup would need my actual LinkedIn ads account, which I'm not linking just to evaluate. I've seen how connecting works though — canceling and heading to Docs or API keys, since the MCP setup details are what I actually came for.”
Declan reached the Connected accounts grid in under ten steps and opened the LinkedIn Ads card. The connect sheet offers exactly two doors: authorize a real account via OAuth, or book fifteen minutes with the team to have it connected for you. For an evaluator who is not ready to hand over a live ad account in his first session, the data layer — the thing the MCP pitch is about — stays on the other side of that door.
Why this costs trust
The strongest moment of the product (endpoint on the first screen) hands off to the weakest (nothing to query until you connect production credentials). Trial momentum dies exactly where the aha was promised.
Actor friction note · Step 12 · verbatim
The only self-serve path to see a platform's data is full OAuth against a live ad account — there's no demo mode or sample data to evaluate with. As someone who wants to test API/MCP capabilities before committing, that's a real evaluation barrier.
What to restore
Ship a demo workspace or read-only sample account so `list platforms` and one sample performance query succeed before any OAuth. Even canned data would let the MCP loop close in the first session.
Evidence boundary: Observed on the pages this session visited (overview, install, campaign IDE, Connected accounts, LinkedIn connect sheet). A sample path living elsewhere (docs, API keys, other cards) would not have been seen.

Why this costs trust
Cognitive load lands on the page where the developer is closest to success; every extra block dilutes the copy-paste moment.
Actor friction note · Step 6 · verbatim
The install page mixes developer setup with a WhatsApp/SMS mobile-alerts signup, which is noise for me — I'm here for the API layer, not text notifications. Mild distraction, easy to ignore.
What to restore
Keep the install screen single-purpose; move channel signup to settings or a post-install nudge.
Evidence boundary: One persona's read of one page; the signup block may convert elsewhere.
