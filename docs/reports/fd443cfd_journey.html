UX/UI Frictions

1. 'Connecting…' never resolves, errors or times out.
Time the attempt out, state what failed, and offer a retry. An indefinite disabled button with no feedback is the most damaging state in the product — it stops a pre-sold engineer at the first integration.
2. The connect flow depends on a popup that browsers block by default.
Detect the blocked popup and continue inline or via redirect. Manual reproduction confirmed the same hang in a normal browser, so this reaches real customers, not just automation.
3. The only failure signal is a corner toast the user never sees.
If a popup is genuinely required, say so inside the modal where attention already is, with a button that reopens it.
4. Failed attempts leave no trace in the Connections list.
After two stalled attempts the list was still empty, so there was no way to tell whether anything had been created. Record attempts with their state.
